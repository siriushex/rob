# MCP Server Setup for Ubuntu

Этот репозиторий содержит пример сервера Model Context Protocol и вспомогательный
скрипт `setup_and_run_mcp_server.sh`, который устанавливает все необходимые
зависимости, проверяет установку и запускает сервер.

## Структура проекта

- `setup_and_run_mcp_server.sh` — основной скрипт установки и запуска.
- `mcp_server.py` — демонстрационный MCP сервер с двумя инструментами (`echo` и
  `current_time`).

## Требования

- Ubuntu 20.04 или новее.
- Возможность выполнять команды `apt-get` от имени root или с помощью `sudo`.

## Быстрый старт

```bash
chmod +x setup_and_run_mcp_server.sh
./setup_and_run_mcp_server.sh
```

Скрипт выполнит следующие шаги:

1. Проверит, что операционная система — Ubuntu.
2. Установит системные пакеты: `python3`, `python3-venv`, `python3-pip`, `git`, `curl`.
3. Создаст виртуальное окружение Python в `.venv` (если оно отсутствует).
4. Установит пакет `mcp[cli]` (по умолчанию версии `1.14.0`).
5. Выполнит проверку зависимостей (`pip check`) и проверку синтаксиса сервера.
6. Запустит MCP сервер из файла `mcp_server.py`.

## Дополнительные параметры

Скрипт поддерживает параметры командной строки:

- `--transport <stdio|sse|streamable-http>` — выбрать транспорт для запуска сервера.
- `--skip-install` — пропустить установку зависимостей (предполагается, что `.venv`
  уже создано и содержит пакет `mcp`).

Можно также использовать переменные окружения:

- `MCP_TRANSPORT` — транспорт по умолчанию.
- `MCP_SERVER_FILE` — путь к Python-файлу с сервером.
- `VENV_DIR` — каталог виртуального окружения.
- `MCP_VERSION` — версия пакета `mcp`.
- `MCP_HOST` и `MCP_PORT` — задают адрес и порт HTTP-сервера (используются в `mcp_server.py`).

## Проверка

После установки скрипт автоматически запускает сервер. Чтобы убедиться, что все
работает, можно выполнить команду `mcp dev mcp_server.py` из созданного окружения
или использовать любой клиент, поддерживающий MCP.
